# Проект модуля 1. Доска заявок ИТ-отдела

Вариант: **ИТ-отдел**

Доска заявок для ИТ-специалистов: принимает заявки от сотрудников, показывает их список с категорией и статусом. Данные хранятся в `localStorage`.

## Выполненные обязательные требования

- Форма добавления заявки: тема, описание, категория (компьютер, проектор, принтер, интернет)
- Список заявок с отображением темы, категории и статуса
- Удаление заявки из списка
- Данные сохраняются в `localStorage` и восстанавливаются после перезагрузки
- Компоненты: `Header`, `RequestCard`, `RequestForm`

## Как запустить

```sh
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Для проверки сборки:

```sh
npm run build
npm run lint
```
