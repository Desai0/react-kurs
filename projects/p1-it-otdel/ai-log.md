# Журнал работы с ИИ

Проект первого модуля — доска заявок без базы данных. Код написан самостоятельно. ИИ использовался для проверки финального кода на соответствие требованиям, проверки работы форм и localStorage, а также для проверки линтера и сборки.

- Проверил, что `npm run build` и `npm run lint` проходят без ошибок.
- Проверил сохранение заявок в `localStorage` после перезагрузки страницы.
- Проверил отображение категорий и статусов заявок.
