# Журнал работы с ИИ

## Подготовка к сдаче, 13.11.2026

Основной код проекта написал сам. Для подготовки к сдаче попросил ИИ проверить проект по требованиям, помочь с недостающими страницами и собрать материалы.

- ИИ нашёл репозиторий и опубликованный сайт, посмотрел существующие скрипты и настройки GitHub Actions.
- Добавил страницы сайтов с историей, страницу «О проверке» и страницу для неизвестного адреса. Для переходов использовал адреса с `#`, чтобы страницы открывались после обновления на GitHub Pages.
- Поправил сравнение результатов для бота: при первой проверке сообщения нет, при повторении прежнего состояния тоже. Добавил проверку этой логики.
- Поправил сохранение результатов в Actions на случай, если в файле не оказалось изменений.
- Проверил сборку, линтер и тесты уведомлений. Изменения отправлены в репозиторий мониторинга, ночной процесс запущен вручную для проверки сохранения результатов и публикации.
- Ручной запуск Actions завершился успешно: пять сайтов ответили, новая проверка появилась на сайте, сообщение без изменения состояния не отправилось. На опубликованном сайте проверил переходы, обновление страниц и неизвестный адрес.
- Подготовил этот отчёт и добавил мой скриншот тестового сообщения бота. Секреты бота в отчёт и файлы для сдачи не добавлял.
