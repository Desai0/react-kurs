## Что получилось

Веб-приложение для чтения ежедневных новостей из RSS-лент, суммаризированных локальной нейросетью. Поиск по заголовку и пересказу, фильтрация по тегам, отметка прочитанных с сохранением в `localStorage`, вечерная сводка в Telegram.

## Выполненные задания

- **Задание 1** — загрузка дайджеста и карточки новостей (`types.ts`, `digest.ts`, состояния loading/error)
- **Задание 2** — поиск по тексту, фильтр по тегу, чекбокс «Только непрочитанные», счётчик со склонением
- **Задание 3** — отметка «прочитано», сохранение в `localStorage`, восстановление после перезагрузки
- **Задание 4** — доступность WCAG AA (Lighthouse 100), GitHub Actions CI/CD с lint + test + build + deploy

## Архитектура

- Бэкенд: n8n в Docker + Ollama (qwen3:4b) читает RSS-ленты Хабр / 3DNews / iXBT утром в 8:00
- Google Apps Script дедуплицирует и хранит новости в Google Таблице
- Вечером в 19:00 n8n присылает сводку в Telegram-бот
- Фронтенд: React 19, TypeScript, Vite, опубликован на GitHub Pages
