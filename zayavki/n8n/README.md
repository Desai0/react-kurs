# ИИ-диспетчер

Два процесса n8n используют коллекцию `it_requests` и категории доски: компьютер, проектор, принтер и интернет. Шаблоны взяты из главы А2 курса и не содержат токена или номера чата.

1. Создайте Telegram-бота и узнайте ID чата. Скопируйте `.env.example` в `.env` в папке `zayavki` и укажите токен. Не публикуйте `.env`.
2. Запустите Ollama на компьютере и загрузите модель. Затем из папки `zayavki` запустите службы:

   ```sh
   ollama pull qwen2.5:3b
   docker compose up -d --build pocketbase n8n
   ```

3. Откройте `http://localhost:5678`, создайте учётную запись n8n и добавьте Telegram credential с токеном бота. Импортируйте `ii-dispetcher.json` и `knopka-vzyat.json` через меню импорта n8n.
4. В процессе «ИИ-диспетчер» выберите Telegram credential и укажите ID чата в узле «Telegram». В процессе «Кнопка «Взять»» выберите ту же credential во всех узлах Telegram. Сохраните и опубликуйте оба процесса. Старый процесс модуля 1 на `/webhook/zayavka` нужно снять с публикации.
5. Запустите доску на `http://localhost:5173`. Добавьте заявку и дождитесь сообщения бота. Кнопка «Взять» меняет статус на «В работе» с задержкой до 10 секунд, после чего статус обновляется на доске.

В выгрузке n8n обращается к PocketBase по имени службы Docker, а к Ollama по адресу `host.docker.internal:11434`. Ollama должна быть доступна из контейнера. Можно запустить Ollama в Docker командой `docker compose up -d ollama`, загрузить модель через `docker compose exec ollama ollama pull qwen2.5:3b` и заменить адрес модели в n8n на `http://ollama:11434/api/chat`.

Процесс кнопки использует Telegram `getUpdates`, поэтому для этого бота не должно быть другого активного обработчика нажатий или Telegram webhook.
