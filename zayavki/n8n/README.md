# ИИ-диспетчер

Два процесса n8n используют коллекцию `it_requests` и категории доски: компьютер, проектор, принтер и интернет. Шаблоны взяты из главы А2 курса и не содержат токена или номера чата.

1. Создайте Telegram-бота и узнайте ID чата. Скопируйте `.env.example` в `.env` в папке `zayavki` и укажите токен. Не публикуйте `.env`.
2. Из папки `zayavki` запустите службы и загрузите модель:

   ```sh
   docker compose up -d --build
   docker compose exec ollama ollama pull qwen2.5:3b
   ```

3. Откройте `http://localhost:5678`, создайте учётную запись n8n и добавьте Telegram credential с токеном бота. Импортируйте `ii-dispetcher.json` и `knopka-vzyat.json` через меню импорта n8n.
4. В процессе «ИИ-диспетчер» выберите Telegram credential и укажите ID чата в узле «Telegram». В процессе «Кнопка «Взять»» выберите ту же credential в обоих узлах Telegram. Сохраните и опубликуйте оба процесса. Старый процесс модуля 1 на `/webhook/zayavka` нужно снять с публикации.
5. Запустите доску на `http://localhost:5173`. Добавьте заявку и дождитесь сообщения бота. Кнопка «Взять» меняет статус на «В работе» с задержкой до 10 секунд, после чего статус обновляется на доске.

В шаблонах n8n обращается к PocketBase и Ollama по именам служб Docker. Процесс кнопки использует Telegram `getUpdates`, поэтому для этого бота не должно быть другого активного обработчика нажатий или Telegram webhook.
